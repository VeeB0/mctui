# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Описание каждого релиза на GitHub берётся из раздела этой версии.

## [Unreleased]

### Добавлено
- **Предупреждения о нагрузке**: низкий TPS (< 15 дольше минуты), компьютеру не хватает памяти,
  на диске сервера меньше 2 ГиБ, `OutOfMemoryError` в логе. Показываются на вкладке «Статус» и значком ⚠
  в списке серверов, пишутся в лог.
- **Уведомления рабочего стола** (macOS, Linux) о предупреждениях и падениях сервера — даже когда окно
  mctui закрыто. Отключаются в «Настройках» (`notify = false`).

### Исправлено
- RCON-сервер сразу становится «недоступен», когда сервер закрывает соединение, — раньше статус
  «онлайн» держался до следующего опроса (до 10 с).

## [0.2.0] — 2026-11-13

### Добавлено
- **Фоновая служба** `mctui daemon`: серверы продолжают работать после закрытия окна (`Ctrl+Q`),
  при следующем запуске окно подключается обратно с логами и графиками. В меню выхода `s` — остановить всё.
- **Автозапуск** службы при входе в систему (macOS — LaunchAgent, Linux — systemd `--user`,
  Windows — ключ `Run`) и серверов с `autostart = true`. Команды `mctui daemon status|stop|restart`,
  `mctui autostart on|off`.
- **Расписание**: авто-бэкап каждые N часов (`backup_every_hours`), ежедневные рестарты (`restart_times`)
  с предупреждениями игрокам в чат за 15, 5 и 1 минуту и обратным отсчётом.
- **Восстановление из бэкапа** (`r` на вкладке «Бэкапы»): текущий мир сначала откладывается
  в `.mctui-before-restore/`.
- Вкладка **«Доступ»**: белый список, операторы, баны игроков и IP — командами, если сервер запущен,
  или правкой файлов, если остановлен.
- Вкладка **«Плагины»**: список `plugins/` и `mods/`, включение/выключение, обновления через Modrinth.
- **Tab-дополнение** команд и ников в строке ввода; источник **«💬 Чат»** на экране логов с отправкой `say`.
- **Графики** игроков, TPS, RAM и CPU на вкладке «Статус».
- **Создание сервера с нуля**: Paper / Purpur / Fabric / Vanilla, выбор версии, памяти и порта,
  принятие EULA, скачивание Java (Adoptium) при необходимости.
- **Английский интерфейс**: по языку системы, `language = "en"` в `servers.toml` или `MCTUI_LANG=en`.
- Установка через **Homebrew**: `brew install VeeB0/mctui/mctui` (формула обновляется при каждом релизе).

### Изменено
- Серверами теперь управляет служба, а не окно. Сервер, запущенный окном версии 0.1.x, нужно остановить
  перед обновлением.
- При установке через Homebrew `mctui update` подсказывает `brew upgrade mctui`.

## [0.1.1] — 2026-11-13

### Добавлено
- Вкладка «Игроки»: операторы помечены «Оп» справа.

### Исправлено
- `install.sh` всегда прописывает `~/.local/bin` в `PATH` в файле запуска оболочки — `mctui` находится
  в новом окне терминала.

## [0.1.0] — 2026-11-13

Первый выпуск.

### Добавлено
- TUI для серверов Minecraft: локальные (mctui запускает процесс) и удалённые по RCON.
- Вкладки «Статус», «Игроки», «Настройки» (`server.properties` с сохранением комментариев), «Бэкапы».
- Отдельный экран логов: живой вывод, `latest.log`, архивы `*.log.gz`, поиск, фильтр по уровню.
- Старт / стоп / рестарт, авто-рестарт при падении (пауза после 3 падений за 5 минут).
- Бэкапы `.tar.gz` с `save-off` / `save-all flush` / `save-on` и ротацией.
- Включение RCON одной клавишей для TPS и точного списка игроков.
- Экран добавления сервера: путь к папке — и mctui сам находит скрипт запуска, Java, порт и мир.
- `mctui update` — обновление из GitHub Releases с проверкой SHA-256; установщики для macOS, Linux и Windows.
- Мышь, история команд, хоткеи в русской раскладке.
