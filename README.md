# mctui — TUI для серверов Minecraft

Один терминальный интерфейс для локальных серверов (mctui сам запускает процесс) и удалённых (по RCON).

## Установка

**macOS / Linux** (Apple Silicon и Intel, x86_64 и arm64):
```bash
curl -fsSL https://github.com/VeeB0/mctui/releases/latest/download/install.sh | sh
```

**Windows 10 / 11** (PowerShell):
```powershell
irm https://github.com/VeeB0/mctui/releases/latest/download/install.ps1 | iex
```

Программа ставится в `~/.local/bin` (Windows: `%LOCALAPPDATA%\Programs\mctui`) и добавляется в `PATH`.
После этого в новом окне терминала достаточно набрать:
```bash
mctui
```

## Обновление
```bash
mctui update
```
Скачивает последний релиз, проверяет SHA-256 и заменяет программу. Настройки не трогаются.
Когда выходит новая версия, mctui показывает в шапке значок `⬆ vX.Y.Z`. Повторный запуск установщика тоже обновляет.

## Первый запуск и настройки
При первом запуске mctui просит вставить путь к папке сервера (`Cmd+V` / `Ctrl+V` или перетащите папку
в окно терминала) — и сам находит скрипт запуска (`start.sh`, `run.bat`…) или `.jar`, встроенную Java,
порт и мир. Можно выбрать и удалённый сервер по RCON. Позже: `a` — добавить сервер, `Del` — убрать из списка.

Список серверов хранится отдельно от программы:

| Система | Файл |
|---|---|
| macOS, Linux | `~/.config/mctui/servers.toml` |
| Windows | `%APPDATA%\mctui\servers.toml` |

Его можно править руками (все поля — в [`servers.example.toml`](servers.example.toml)), указать другой файл —
`mctui --config путь` или переменная `MCTUI_CONFIG`.

## Сборка из исходников
```bash
cargo install --git https://github.com/VeeB0/mctui
# или
cargo build --release && ./target/release/mctui
```

## Экран
- Слева — серверы, справа вкладки **Статус · Игроки · Настройки · Бэкапы**, внизу ответ на команду и строка ввода.
- Логи на главном экране не показываются: кнопка **«L · Логи»** в правом верхнем углу (клик мышью или `L` / `Ctrl+L`)
  открывает отдельный экран — живой вывод, `latest.log` и архивы `*.log.gz`.

## Клавиши
| Где | Клавиши |
|---|---|
| Везде | `Ctrl+S` старт · `Ctrl+X` стоп · `Ctrl+R` рестарт · `Ctrl+B` бэкап · `Ctrl+L` логи · `Ctrl+Q` выход |
| Главный экран | `↑↓` сервер · `a` добавить сервер · `Del` убрать · `Tab` фокус · `1–4` вкладки · `Enter`/`:` ввод команды · `L` логи |
| Ввод команды | `Enter` отправить · `↑↓` история · `Esc` выйти |
| Игроки | `k` кик · `b` бан · `o`/`d` оп/деоп |
| Настройки | `Enter` изменить · `Пробел` true/false · `r` включить RCON · `u` перечитать |
| Бэкапы | `n` новый · `d` удалить · `u` обновить |
| Логи | `↑↓ PgUp PgDn` · `g/G` начало/конец · `←→` · `/` поиск · `n/N` выше/ниже · `f` фильтр · `Tab` источники · `Esc` назад |

Хоткеи работают и в русской раскладке.

## Как это устроено
- **Локальный сервер**: процесс из `command` в папке `dir`, команды — через stdin. Остановка — `stop`, через
  `stop_timeout_secs` — kill. При падении — авто-рестарт; после 3 падений за 5 минут он приостанавливается.
- **TPS и игроки** берутся по RCON (опрос `list`/`tps` раз в 10 с). Для локального сервера RCON включается
  на вкладке «Настройки» клавишей `r` (случайный пароль, `broadcast-rcon-to-ops=false`). Без RCON игроки
  считаются по строкам лога «joined/left the game».
- **Бэкап**: `save-off` → `save-all flush` → ожидание «Saved the game» → `.tar.gz` из `backup_paths` → `save-on`.
  Хранятся последние `backup_keep` архивов.
- **Выход** при запущенных серверах: mctui сначала штатно останавливает их. Повторный `Ctrl+Q` — убить сразу.
